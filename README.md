# Cricketer Favorites App

A simple and beginner-friendly React mini-project that allows users to like or unlike their favorite Indian cricketers.

## Features
- Displays a list of 20 Indian cricketers using reusable React components.
- Uses React `useState` to manage independent "like" states for each cricketer.
- Demonstrates passing data via `props`.
- Clean and minimal UI.

## How to Run

1. Make sure you have Node.js installed.
2. Clone or download this project.
3. Open the terminal in the project folder and install dependencies:
   npm install
   
5. Start the development server:
   npm run dev
   
6. Open your browser and go to `http://localhost:5173`.
